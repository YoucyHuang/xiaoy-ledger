# 小Y 的四个篮子

小Y星球笔记系列里的记账小工具。用长线的眼光记账，只分四个篮子：

- **生活**：吃饭、穿衣、看病、出行、玩
- **住房**：房租、房贷、物业、水电
- **保险**：医疗、重疾、意外、寿险
- **投资**：ETF、基金、债券、股票

分类少，ADHD 也记得下去。定投、房租这类固定支出设一次就行，以后打开会自动补记。

**在线使用**：https://youcyhuang.github.io/xiaoy-ledger/

装到手机桌面：
- iPhone：用 Safari 打开，点分享按钮，选「添加到主屏幕」
- 安卓：用 Chrome 打开，点菜单，选「安装应用」

账本只存在你自己设备的浏览器里，不上传。换设备前请在「固定」页导出备份。本工具只帮你记账，不提供投资建议。

改了文件后，把 `sw.js` 里的 `VERSION` 加一，已经装好的手机会自动更新。
